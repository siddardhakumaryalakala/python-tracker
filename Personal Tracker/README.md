# 🐍 Python 30-Day Mastery Tracker & Daily Push Hub

A complete, full-stack 30-day Python learning curriculum with:
- 📱 **Automated Daily Push Notifications** powered by GitHub Actions & ntfy.sh (No accounts, no API keys, zero maintenance).
- 🌐 **Interactive Web Dashboard** hosted on Vercel with progress persistence.
- ⏱ **Built-in 1-Hour Phase Timer** (15m Concept + 25m Code + 15m Solve + 5m Review).
- 📋 **Code Snippets & Copy Buttons** for all 30 days.

---

## 🚀 Live Cloud Deployment

### 1. GitHub Actions (Automated 9:00 AM Daily Alerts)
Runs `.github/workflows/daily_reminder.yml` automatically every morning at **09:00 AM IST** to send your daily topic roadmap and 1-hour study schedule directly to your phone.

### 2. Vercel (Web Dashboard)
Hosts `index.html` worldwide with instantaneous load times on any phone, tablet, or PC.

---

## 💻 Local Usage
To run the full-stack server locally on your machine:
```powershell
python app.py
```
Open **http://127.0.0.1:5000** in your browser.
